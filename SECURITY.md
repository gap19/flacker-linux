# Security policy

FLACker reads local files that may be malformed (FLAC metadata, images, playlists, lyrics). Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository.

Include the affected version, a description and, when possible, a minimal synthetic file that reproduces the problem. Do not send music, lyrics or private documents.

GTK, GStreamer and codecs come from your distribution; keep them updated. FLACker never downloads code or updates itself.
